# Referências e Bases Recomendadas

## Bases de dados
- ONS: dados da rede básica, linhas e subestações.
- ANEEL: empreendimentos de geração, outorgas e dados setoriais.
- EPE: estudos de expansão energética.
- IBGE: malhas territoriais, população e dados socioeconômicos.
- INPE/CRESESB: dados solarimétricos.
- Atlas Eólico Brasileiro: dados de velocidade do vento.
- MMA/ICMBio: unidades de conservação.

## Referências metodológicas
- Análise multicritério espacial.
- Weighted Linear Combination.
- AHP.
- TOPSIS.
- Planejamento da expansão da geração.
- Sistemas de transmissão de energia elétrica.
